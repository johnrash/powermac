# Provenance: what came from the BeBox emulator

PowerMac began as a copy of the BeBox emulator's portable core, tools and
Haiku application. The two trees are separate repositories, so a fix in a
shared file has to be ported by hand. This table says which files can take
a fix unchanged and which have diverged.

The table is generated by `tools/provenance.py BEBOX`, which compares each
file with its origin in the BeBox emulator's source tree BEBOX after undoing
the mechanical renames (namespace `bebox` to `powermac`, include guards
`BEBOX_` to `PM_`, the file header). Run it again after changing shared
files.

- **Same**: identical apart from the renames. A fix ports both ways as it is.
- **Changed**: shares its origin but has diverged. Port fixes with care; the
  note says what is different.
- **New**: PowerMac's own.

The Haiku application (`src/haiku/`) was adapted for the 9500 in
milestone M4: the ADB keyboard and mouse, no LED columns or game ports,
the 9500's preferences and media menu.

Fixes made here that the BeBox emulator still needs:

- `MachineWindow::_SaveScreenshot` deleted an uninitialized pointer when
  `BBitmapStream::DetachBitmap()` failed (a screenshot of an invalid
  frame crashed the window thread). It now starts at `nullptr` and is
  deleted only on success.
